မင်္ဂလာ QR ဖိတ်စာ — အသုံးပြုနည်း
=====================================

★ စာသား / ဓာတ်ပုံ / သီချင်း ပြင်ရန် — admin.html ကို Chrome (သို့) Edge ဖြင့် ဖွင့်ပါ ★
   - Code မပြင်ရပါ။ Form တွင် ရိုက်ထည့်/ပုံရွေးရုံဖြင့် ညာဘက် Preview တွင် ချက်ချင်း ပြောင်းမည်။
   - Tab များ: ① အခြေခံ  ② စာသား (၅ ဘာသာ)  ③ ဓာတ်ပုံ  ④ Our Story Album  ⑤ ခလုတ်စာသား  ⑥ သီချင်း/ထုတ်ယူ
   - ပြင်သမျှ Browser ထဲတွင် အလိုအလျောက် သိမ်းသည် (ပိတ်ပြီး ပြန်ဖွင့်လည်း ကျန်နေမည်)။
   - ပြီးလျှင် "⬇ Website ZIP ထုတ်မည်" → Unzip → Netlify Drop သို့ folder ဆွဲထည့်ပါ။
   - ကွန်ပျူတာ တခြားတစ်လုံးတွင် ဆက်ပြင်ရန် ⑥ → "Project ဖိုင် သိမ်းမည်/ဖွင့်မည်"။

ဖိုင်များ
---------
admin.html      → ★ Admin (ပြင်ဆင်ရန် နေရာ)
index.html      → ဧည့်သည်များ QR Scan ဖတ်ပြီး ဖွင့်မည့် Website (စာအိတ်ဖွင့် animation, Countdown,
                   Our Story album, Gallery, မြေပုံ, Calendar, RSVP, Music)
card.html       → Print ထုတ်မည့် QR ဖိတ်စာကတ် (5x7 inch) + QR ထုတ်စက်
js/config.js    → နာမည်၊ ရက်စွဲ၊ နေရာ၊ ဖုန်း၊ ဓာတ်ပုံစာရင်း (ဘာသာ ၅ မျိုးစလုံး) — အဓိက ပြင်ရမည့်ဖိုင်
js/i18n.js      → ခလုတ်/ခေါင်းစဉ် စာသားများ ဘာသာ ၅ မျိုး (English, တႆး, မြန်မာ, 中文, ไทย)
js/qrcode.js    → QR library (Offline အလုပ်လုပ်သည်)
photos/         → ဓာတ်ပုံများ
music/          → နောက်ခံ သီချင်း (song.mp3)

၁။ အချက်အလက် ပြင်ရန်
   js/config.js ကို Text editor ဖြင့်ဖွင့်၍ နာမည်၊ မိဘအမည် (ဦး ——— နေရာ)၊ ရက်စွဲ၊ ဖုန်းနံပါတ် ပြင်ပါ။

၂။ ဓာတ်ပုံ ထည့်ရန်
   photos/ ထဲက cover.jpg, 01.jpg ... 12.jpg ကို သင့်ပုံများဖြင့် နာမည်တူ အစားထိုးပါ။
   - cover.jpg = ထောင်လိုက်ပုံ (ဥပမာ 1080x1440)
   - ပုံတစ်ပုံလျှင် 300–500 KB ခန့် ချုံ့ထားပါ (ဖုန်းတွင် မြန်မြန်ပွင့်ရန်)
   ပုံ ၃၀ အထိ ထပ်ထည့်လိုပါက config.js ၏ story / gallery စာရင်းထဲ ထပ်ရေးပါ။

၃။ သီချင်း ထည့်ရန် (မထည့်လည်းရ)
   music/song.mp3 အမည်ဖြင့် ထည့်ပါ။ စာအိတ်ဖွင့်လိုက်သည်နှင့် စဖွင့်မည်။

၄။ Internet ပေါ်တင်ရန် (အခမဲ့)
   - Netlify Drop: https://app.netlify.com/drop  → wedding-invitation folder တစ်ခုလုံးကို ဆွဲထည့်ရုံ
   - (သို့) GitHub Pages
   ရလာသော Link ကို config.js ၏ siteUrl တွင် ထည့်ပါ။

၅။ QR ကတ် ထုတ်ရန်
   card.html ကိုဖွင့် → Link ထည့် → "QR ထုတ်မည်" → "Print / PDF"
   (Print setting: Paper size 127 x 178 mm, Margin = None, Background graphics = On)
   QR သည် သင့် Website သို့ တိုက်ရိုက်သွားသဖြင့် Video ထဲကလို ကြော်ငြာ/IQ Test စာမျက်နှာ မပေါ်ပါ။
   Print မထုတ်ခင် ဖုန်းဖြင့် Scan ဖတ်၍ စမ်းပါ။

၆။ ဘာသာ ၅ မျိုး
   - Website အပေါ်ညာဘက် 🌐 ခလုတ် (နှင့် စာအိတ်စာမျက်နှာ အပေါ်) တွင် ဘာသာပြောင်းနိုင်သည်။
   - QR ဖွင့်လျှင် ဖုန်း၏ဘာသာ (中文/ไทย) ကို အလိုအလျောက် ရွေးပေးသည်၊ မဟုတ်ပါက config.js ၏ defaultLang။
   - Link နောက်တွင် ?lang=shn / ?lang=zh / ?lang=th / ?lang=en / ?lang=my ထည့်၍ ဘာသာ သတ်မှတ်နိုင်သည်။
   - card.html တွင် "ကတ်ဘာသာ" ရွေး၍ ဘာသာတစ်မျိုးချင်း ကတ် Print ထုတ်နိုင်သည်၊
     "QR ဖွင့်လျှင်" ရွေး၍ (ဥပမာ တရုတ်ဧည့်သည်အတွက် 中文) QR သီးသန့် ထုတ်နိုင်သည်။
   - ဘာသာပြန်ထားသော စာသားများ (အထူးသဖြင့် တႆး) ကို Print မထုတ်မီ ပြန်စစ်ပေးပါ။
