မင်္ဂလာ QR ဖိတ်စာ — အသုံးပြုနည်း (LM STUDIO)
=================================================

★ စာသား / ဓာတ်ပုံ / သီချင်း ပြင်ရန် — admin.html ကို Chrome (သို့) Edge ဖြင့် ဖွင့်ပါ ★
   Code ပြင်စရာ မလိုပါ။ ဘယ်ဘက်တွင် ပြင်လိုက်သည်နှင့် ညာဘက် Preview တွင် ချက်ချင်း ပြောင်းမည်။
   ပြင်သမျှ Browser ထဲတွင် အလိုအလျောက် သိမ်းသည် (Folder တစ်ခုချင်း သီးခြား)။

   ① အခြေခံ      — Monogram, ရက်စွဲ/အချိန် (✨ ခလုတ်ဖြင့် ၅ ဘာသာ အလိုအလျောက်), နေရာ, Map, ဖုန်း, Website Link
   ② စာသား       — နာမည်, မိဘအမည်, ဖိတ်ကြားစာ … (ဘာသာ ၅ မျိုး)
   ③ ဓာတ်ပုံ      — Cover ပုံ, Gallery ပုံများ (ထည့်/ဖျက်/နေရာရွှေ့)
   ④ Album       — Our Story စာမျက်နှာများ (ပုံစံ ၄ မျိုး)
   ⑤ ခလုတ်စာသား  — Website ပေါ်ရှိ ခလုတ်/ခေါင်းစဉ်ငယ် စာသားများ
   ⑥ သီချင်း/ထုတ်ယူ — MP3 သီချင်း, Website ZIP ထုတ်ရန်, Project Backup

ဖိုင်များ
---------
admin.html      → ★ ပြင်ဆင်ရန် နေရာ
index.html      → ဧည့်သည်များ QR Scan ဖတ်ပြီး ဖွင့်မည့် Website
card.html       → Print ထုတ်မည့် QR ဖိတ်စာကတ် (5x7 inch / 127x178 mm)
js/, css/, fonts/ → Website အလုပ်လုပ်ရန် ဖိုင်များ (မပြင်ပါနှင့်)
photos/, music/ → ဓာတ်ပုံ / သီချင်း (admin မှ ထည့်ပါ)

---------------------------------------------------------------
၁။ အတွဲသစ် (သတို့သား/သတို့သမီး) တစ်တွဲ စလုပ်ရန်
---------------------------------------------------------------
   - ဒီ Template folder ကို မပြင်ဘဲ သိမ်းထားပါ။
   - Copy ကူး၍ folder အမည်ပြောင်းပါ (ဥပမာ wedding-aung-may) → အဲဒီထဲက admin.html ဖွင့်ပါ။
   - အတွဲတစ်တွဲ = Folder တစ်ခု = Cloudflare Project တစ်ခု = Link/QR တစ်ခု

---------------------------------------------------------------
၂။ Internet ပေါ် တင်ရန် (Cloudflare Pages — အခမဲ့ Hosting)
---------------------------------------------------------------
   1. admin ① “Website Link” တွင် https://aung-may.သင့်domain.com ကို ကြိုထည့်ပါ
   2. “⬇ Website ZIP ထုတ်မည်” နှိပ်ပါ
   3. dash.cloudflare.com → Workers & Pages → Create application → Pages
      → Drag and drop your files → Project name (ဥပမာ aung-may) → ZIP ဆွဲထည့် → Deploy site
   4. Project → Custom domains → Set up a custom domain → aung-may.သင့်domain.com → Activate
   5. ပြင်ဆင်ပြီး ပြန်တင်လိုလျှင်: ZIP ထပ်ထုတ် → Project → Create new deployment (Link မပြောင်းပါ)

   ကိုယ်ပိုင် Domain ကို Cloudflare ထဲ ထည့်ခြင်း (တစ်ကြိမ်သာ):
      Cloudflare → Add a domain → Free → ပေးလာသော Nameserver ၂ ခုကို
      Domain ဝယ်ခဲ့သော ဆိုဒ်ရှိ Nameservers → Custom DNS တွင် အစားထိုးပါ → Active ဖြစ်သည်အထိ စောင့်ပါ။

---------------------------------------------------------------
၃။ QR ကတ် Print ထုတ်ရန်
---------------------------------------------------------------
   - card.html ဖွင့် → Link မှန်ကြောင်း စစ် (အနီရောင် “နမူနာ Link” မပေါ်ရ)
   - ကတ်ဘာသာ ရွေး → QR အရောင် အနက်/အညိုရင့် (ရွှေရောင်ထက် Scan ဖတ်ရ ပိုလွယ်)
   - Print: Paper 127 x 178 mm, Margins = None, Background graphics = ✓  (ပုံနှိပ်ဆိုင်အတွက် Save as PDF)
   - ကတ်တစ်ကတ် အရင်ထုတ်၍ ဖုန်း ၂–၃ လုံးဖြင့် Scan စမ်းပြီးမှ အများထုတ်ပါ။

---------------------------------------------------------------
၄။ သိထားရန်
---------------------------------------------------------------
   - ဖောင့်များ Website ထဲတွင် ပါပြီးသား (Google Fonts မသုံး) — Website ပွင့်လျှင် VPN မလိုပါ။
   - ဘာသာ: ဧည့်သည်ဖုန်းဘာသာ (中文/ไทย) ကို အလိုအလျောက် ရွေးသည်။ Link နောက်တွင်
     ?lang=en / shn / my / zh / th ထည့်၍လည်း သတ်မှတ်နိုင်သည်။
   - ရက်စွဲ ကျော်လွန်သွားလျှင် Countdown အစား “မင်္ဂလာပွဲ ပြီးဆုံးပါပြီ” စာ ပြမည်။
   - ကွန်ပျူတာ တခြားတစ်လုံးတွင် ဆက်ပြင်ရန်: ⑥ → Project ဖိုင် သိမ်းမည် / ဖွင့်မည်။
   - Domain သက်တမ်းကို နှစ်စဉ် တိုးပါ (Auto-renew ဖွင့်ထားပါ) — မတိုးလျှင် QR Link ပျက်မည်။
   - ဘာသာပြန် စာသားများ (အထူးသဖြင့် တႆး) ကို Print မထုတ်မီ ပြန်စစ်ပါ။
